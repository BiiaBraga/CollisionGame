# 🚀 Collision Game

## 📚 Sobre o Projeto

Collision Game é um projeto acadêmico desenvolvido durante o primeiro semestre do curso de Ciência da Computação.
O projeto foi criado com o objetivo de praticar lógica de programação, orientação a objetos e desenvolvimento de jogos utilizando Python e a biblioteca Pygame.

---

## 🎮 Funcionalidades

- Movimentação do personagem
- Sistema de colisão
- Mecânicas básicas de jogo
- Renderização gráfica em 2D
- Controle por teclado

## 🛠 Tecnologias Utilizadas
- Python
- Pygame

---

## ⚙️ Como Executar
Clone o repositório
```bash
git clone https://github.com/BiiaBraga/CollisionGame.git
```

Acesse a pasta do projeto
```bash
cd CollisionGame
```

Instale as dependências
```bash
pip install pygame
```

Execute o jogo
```bash
python jogoPygameColisao.py
```
